CODEVILLE

Vibe code. See it build.

A desktop workspace for vibe coding. Your coding agent's work becomes a block town: one building per feature, one block per file, built live while Claude Code writes.

⬇ Download for Windows ▶ Watch the demo

What's in the window

Everything your agent does, drawn so you can see it. No more scrolling through diffs to find out what was built.

Block town

Each feature gets its own district: frontend, backend and test buildings, the database and outside services. Click any block to open the file.

Chat with Claude Code

Send a prompt and watch the edits, tools and sub-agents stream in, while new blocks drop into the town.

Tests you can see

A shopper walks your test steps and stops at the one that fails, with what broke, where, and what to do next.

Project analysis

An agent reads your project: stack, layers, features, how the parts connect, and the commands that test and build it.

Source control

Stage, commit and push in one click. If a push fails, it tells you why and what the next step is.

Hand control

Turn on the camera and the town becomes a hologram. Rotate, zoom and reset with your hands. The camera picture never leaves your computer.

90-second demo

From first run to a pushed commit: analysis, the block town, a live chat build, a failing test, and hand control.

Get started

Codeville runs on Windows. The installer bundles everything it needs, including Python.

  1. Install
    Download Codeville-Setup.exe from the Releases page and run it.
  2. Connect Claude Code
    The welcome screen checks Git, Claude Code and Node.js and shows the plugin commands.
  3. Open a folder
    Open a project, start one from a template, or copy a repository, and watch your town appear.
